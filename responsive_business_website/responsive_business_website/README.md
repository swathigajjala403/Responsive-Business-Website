# Responsive Business Website

A beginner-friendly portfolio project for practicing HTML5, CSS3, JavaScript, and Bootstrap.

## Features
- Responsive navigation bar
- Home, About, Services, and Contact sections
- Bootstrap grid and service cards
- Mobile-friendly styling
- Client-side contact form validation
- Accessible form labels and status message

## How to run
1. Extract the ZIP file.
2. Open the `responsive_business_website` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. An internet connection is required to load Bootstrap from its CDN.

## Files
- `index.html` — page structure and Bootstrap links
- `style.css` — visual styling and responsive adjustments
- `script.js` — contact form validation
- `README.md` — project notes

## Important
The contact form is a front-end demo only. It does not send or store messages. This project does not include WordPress or a backend CMS.
